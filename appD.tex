\chapter{C4-ДЕКОМПОЗИЦИЯ АРХИТЕКТУРЫ}

В~приложении представлена текстовая C4-декомпозиция фактической
архитектуры MVP ИИ-методиста, синхронизированная с текущими сервисами
Adapstory: AI~Course~Generator, RAG-инструмент, граф знаний,
School~BFF и LMS.

\section*{Г.1 --- Системный контекст (C4 Level~1)}

\begin{itemize}
  \item \textbf{Разработчик курса / HR-специалист}: загружает документ,
    запускает подготовку черновика, проверяет структуру и знак качества;
  \item \textbf{School UI / BFF School}: маршрутизирует запросы
    веб-клиента и показывает статус, результат и происхождение;
  \item \textbf{AI Course Generator}: исполняет LangGraph-конвейер
    генерации и хранит артефакты запуска;
  \item \textbf{RAG-контур}: индексирует источник и возвращает
    фрагменты для таблицы свидетельств;
  \item \textbf{Граф знаний}: предоставляет связанные компетенции,
    понятия и предметные связи;
  \item \textbf{Конечная точка LLM}: локальная или OpenAI-совместимая конечная точка
    для моделей семейства Qwen;
  \item \textbf{LMS Adapstory}: принимает утверждённый курс и
    публикует его.
\end{itemize}

\section*{Г.3 --- Компоненты (C4 Level~3)}

\begin{itemize}
  \item \textbf{Узел анализа источника}: строит таблицу свидетельств из RAG-фрагментов
    и резервного фрагмента исходного текста;
  \item \textbf{Узел структуры курса}: генерирует черновик структуры курса и использует
    граф знаний для семантического усиления структуры;
  \item \textbf{Узел подготовки контента}: формирует уроки со встроенными ссылками на источники;
  \item \textbf{Узел проверки фактов}: проверяет утверждения относительно источника;
  \item \textbf{Узел педагогической проверки}: оценивает методологическую связность и покрытие Блума;
  \item \textbf{Узел верификации}: рассчитывает знак качества, происхождение результата и снимок проверки дипломных метрик;
  \item \textbf{Слой проверки человеком}: блокирует публикацию без подтверждения человека;
  \item \textbf{Exporter}: передаёт утверждённый курс в LMS Adapstory.
\end{itemize}
